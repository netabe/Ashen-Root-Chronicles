# 聚宝仙盆之杂灵根才是真 BOSS

一款文字放置修仙游戏，杂灵根专属版本。

## 🎮 特色功能

- **路径选择** - 探索不同修炼路线
- **坊市贸易** - 灵石交易与经济系统
- **宗门建设** - 招募弟子、建造建筑、自动产出
- **秘境挑战** - 10 层守关者体系
- **虚空裂隙** - Lv.1-10 的 boss 挑战
- **妖兽狩猎** - 8 种妖兽掉落资源 + 经验
- **炼丹系统** - 炼制药剂提升修为
- **宠物收集** - 收集培养各类宠物
- **法宝炼制** - 打造强大法宝
- **天命劫难** - 境界突破考验

## 🎯 杂灵根专属天赋

- **万法初通** - 修炼效率 +15%
- **五行亲和** - 坊市交易优惠 20%
- **灵根觉醒** - 战斗伤害 +20%
- **万法归一** - 聚宝仙盆与杂灵根共鸣
- **混沌道体** - 全属性大幅提升
